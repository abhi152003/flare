Tier 1 Quick Wins Hours · mostly display & config

Small, self-contained changes. Low risk, immediate visible payoff. Good warm-up momentum.

01

Path shortening in tab titles

Show ~/work/api instead of full absolute paths in tab titles — same treatment already applied to the palette.

displaytabs
02

Palette styling polish

Improve the command palette: rounded pill indicators, better spacing, a keyboard-hints footer, scrollbar for long lists.

uipalette
03

Use the shell-reported title

Leverage the OSC 0/2 title the shell already emits to show smarter tab names (current command or directory) instead of "Tab 1".

tabsosc
04

Verify clipboard (OSC 52)

Confirm the OSC 52 clipboard copy/paste sequence is fully wired through the stock parser and working end-to-end.

oscverify
05

Named tabs & panes

Let users rename tabs and panes (currently auto-titled). Persist names across sessions.

tabsconfig
06

Atomic session writes

Write session files via temp-file + rename so a crash mid-write can never corrupt the saved state.

reliabilitypersistence
07

Fully configurable keybinds

Make every tab, pane, palette, and split action remappable in the TOML config — not just the hardcoded defaults.

configinput
Tier 2 Focused Features A day or two each · single subsystem

Each touches one well-understood area. Builds on existing infrastructure — no new foundations required.

08

Foreground-process CWD tracking

Follow the directory of the active foreground process group (e.g. a running agent), not just the shell — via tcgetpgrp + /proc.

cwdfoundation
09

Git branch & status display

Show the current git branch and ahead/behind counts in the tab bar or palette entry.

gitdisplay
10

Status dots in the tab bar

Colored dots next to each tab indicating pane state (red = blocked, yellow = working, green = done). At-a-glance visibility.

agentshigh-value
11

Pane zoom

Temporarily expand one pane to fill the whole tab; toggle back to the previous layout with a single key.

panesux
12

Mouse focus on click

Verify and finalize click-any-pane-to-focus so mouse-driven workflows work cleanly with the split layout.

panesinput
13

Agent auto-detection

Recognize when an AI agent starts in a pane by watching process names, title patterns, and OSC codes. Ship detection profiles for common agents.

agentscore
14

Git-based workspace naming

Auto-derive a session's name from the git repo root (walk up from CWD to find .git, use the repo dir as the label).

gitsessions
Tier 3 Multi-Component Several days · crosses subsystems

Features that coordinate between detection, state, rendering, and input. Higher value, moderate complexity.

15

Agent status tracking

Track and display per-pane live status: Blocked / Working / Idle / Done. Agents report state via OSC codes or shell hooks; Flare watches and surfaces it.

agentscore
16

Status filter in the palette

Filter the directory/session switcher to show only "blocked" or "working" agents — quickly find which ones need attention.

paletteagents
17

Agent session resume

When restoring a session, re-launch agents that support resume (e.g. --session <id>) so they pick up where they left off. Store session refs in saved state.

agentspersistence
18

Agent progress reporting

Watch OSC 9 progress sequences some agents emit to show a progress bar or percentage per pane.

agentsosc
19

BSP tiling layout

Replace the current alternating-direction split with a proper binary-space-partition layout — panes split the largest area first. More intuitive geometry.

paneslayout
20

Pane resizing

Drag split borders or use keybinds to resize panes. Currently ratios are fixed at 0.5; make them adjustable.

panesinput
21

Unfocused pane dimming

Subtly dim inactive panes so the focused one stands out — improves readability in multi-pane layouts.

panesrender
22

Auto shell-integration injection

Automatically inject the OSC 7 hooks (and agent hooks) into the shell at startup — no manual .bashrc editing. Detect the shell and apply the right config.

shellux

Introduces new UI surfaces, broader state management, or external-facing interfaces. Worth scoping carefully.

23

Git worktree grouping

Group multiple checkouts of the same repo as one logical "space" — linked worktrees share a project identity in the switcher.

gitsessions
24

Directory history per workspace

Remember recently-visited directories within a project and offer them as quick-switch targets in the palette.

sessionspalette
25

Agent metadata display

Show agent name, model, and elapsed time per pane in a status strip or tooltip.

agentsdisplay
26

Shell-integration hooks for agents

Ship shell scripts that agents source to report their state and session IDs to Flare reliably.

agentsshell
27

Navigator overlay (enhanced palette)

A fuzzy search across all panes, tabs, and workspaces (not just saved directories) — a tree view with status dots.

palettenavigation
28

Stable pane addressing

Give panes durable numbers (w1:p2) that survive close/reopen, so users and scripts can reference them reliably.

panesapi
29

Global status bar

A persistent strip summarizing total agent state across all panes: "3 working, 1 blocked, 2 done".

agentsui
30

Notifications

Desktop notifications when an agent finishes or becomes blocked — even when the window isn't focused.

agentsos
31

Sound alerts

Optional audio cues on agent state changes (blocked → chime, done → success tone).

agentsaudio
32

Tab & pane drag reordering

Reorder tabs by dragging; move panes between tabs with the mouse.

tabspanes
33

JSON socket API

A local socket API so agents and scripts can programmatically spawn panes, read output, switch focus, and query status. Makes Flare scriptable.

apiscriptable
34

CLI pane control

flare msg new-pane, flare msg list-panes — control Flare from the command line or shell scripts.

apicli
35

Onboarding & first-run

Detect missing shell integration and prompt the user to enable it (or auto-inject) on first launch.

uxshell
36

Right-click context menu

Right-click any pane for actions: split, close, rename, zoom, copy.

panesui
37

Built-in settings panel

An in-app settings UI (theme, opacity, session options) instead of hand-editing TOML.

configui
Tier 5 Major Builds Weeks · large, self-contained features

Significant standalone features. Each is a meaningful release on its own.

38

Persistent sidebar dashboard

A left rail listing all workspaces (projects) grouped by git repo, each with a status rollup of its agents. Click to switch projects. The signature multi-agent surface.

uisignature
39

Pane output streaming

Let an external program read a pane's live output via the API — for chaining agents or piping to other tools.

apiagents
40

Pane screen-history replay

Optionally save pane output (scrollback) and replay it on restore, so you see what an agent last printed.

persistenceagents
41

Session import / export

Save a full session to a portable file and load it elsewhere — share workspace setups across machines.

persistenceportability
42

Hyperlink rendering

Render OSC 8 hyperlinks as underlined, clickable links.

renderosc
43

Kitty graphics protocol

Render inline images — agents and screenshot tools frequently emit these.

rendermedia
44

Theme passthrough

Forward the host terminal's color scheme (OSC 10/11) so Flare matches the surrounding environment.

themeosc
45

Compact / mobile layout

A layout mode for small screens — a header + switcher instead of a full sidebar.

uiresponsive
Tier 6 Architectural Rework Weeks–months · foundational shifts

The deepest changes. These reshape how Flare is structured and unlock capabilities nothing else can. Approach with a dedicated plan.

46

Detach / reattach (server model)

Split Flare into a background server (owns the PTYs and processes) and a thin UI client. Closing the window no longer kills agents — you reattach later and everything's still alive. The defining tmux-class capability.

architecturedefining
47

Live handoff

Transfer live PTY file descriptors to a replacement process during updates — agents keep running with no restart needed across Flare upgrades.

architecturereliability
